# 正式实验会话完整性实施计划

> 已由用户确认总体设计；本计划按独立分支、阶段验证和小提交执行。

1. **数据模型与基础设施**：定义判别联合、事件/会话模型、UUID 工具、模式配置和序列化测试。
2. **正式问卷完整性**：将问卷默认值改为 null；增加回答追踪、必答校验与第一个未答聚焦测试。
3. **游戏事件完整性**：让 reducer 产生证据、评分、阶段快照与最终提交事件；加入验证 pending 与点数守恒测试。
4. **沉没成本与提交**：保存选择前后行为、信心、提交类型，并让三个选项视觉等权。
5. **模式中性化**：用 feedbackPolicy 隔离正式/快速 UI，正式模式移除答案暗示并显示正式测评标识。
6. **持久化与 Worker/D1**：实现正式缓存、上传队列、API 客户端、Worker 路由和 D1 migration；实际 D1 绑定使用部署环境的数据库标识。
7. **恢复、退出与错误隔离**：heartbeat、恢复、页面退出、错误边界与错误报告；技术错误使会话无效而非分类。
8. **集成与 E2E**：覆盖重复点击/幂等、刷新恢复、断网补传、正式无暗示、超时、退出与正式全流程。

每一项完成后运行全套测试、类型检查和生产构建，并提交一个语义明确的 commit。
